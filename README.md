# RuJe IA: Seu Assistente Acadêmico

Crie uma plataforma web moderna chamada RuJe IA 🇲🇿, especializada na criação automática de trabalhos escolares, acadêmicos e científicos para estudantes do ensino médio, técnico e universitário.



Design e Identidade Visual



- Nome da plataforma: RuJe IA 🇲🇿

- Cores principais: Branco e Verde.

- Design moderno, elegante e profissional.

- Interface totalmente responsiva para celular, tablet e computador.

- Aparência semelhante a plataformas premium de IA.

- Logo profissional com as letras "RJ" integradas ao nome RuJe IA.



Sistema de Autenticação



Criar sistema completo de autenticação com:



- Cadastro por:

  - Nome completo

  - E-mail

  - Número de telefone

  - Senha

  - Confirmar senha

- Login apenas com:

  - Nome de usuário ou e-mail

  - Senha

- Não utilizar login Google.

- Recuperação de senha por e-mail.

- Criptografia segura das senhas.

- Perfil do usuário editável.



Dashboard Principal



Após login, mostrar:



- Saudação personalizada.

- Histórico de trabalhos criados.

- Botão "Criar Novo Trabalho".

- Área "Meus Downloads".

- Estatísticas de utilização.

- Configurações da conta.

- Outros programas da RuJe IA.



Criação Inteligente de Trabalhos



Ao clicar em "Criar Novo Trabalho", abrir formulário completo contendo:



Informações Acadêmicas



- Tema do trabalho

- Título do trabalho

- Nome do estudante

- Número do estudante

- Curso

- Turma

- Classe/Ano

- Instituição de ensino

- Faculdade

- Departamento

- Disciplina

- Nome do docente

- Cidade

- País

- Data de entrega

- Tipo de trabalho



Tipos Disponíveis



- Trabalho Escolar

- Trabalho Científico

- Monografia

- Projeto de Pesquisa

- Relatório

- Artigo Científico

- Seminário

- Revisão Bibliográfica

- Estudo de Caso

- Dissertação

- TCC



Configurações



- Quantidade de páginas

- Idioma

- Nível acadêmico

- Normas APA

- Normas ABNT

- Normas Vancouver

- Referências automáticas

- Inserir citações automáticas

- Gerar índice automático

- Gerar capa automática



Inteligência Artificial



A IA deve gerar automaticamente:



1. Capa Profissional

2. Folha de Rosto

3. Índice

4. Introdução

5. Objetivos Gerais

6. Objetivos Específicos

7. Fundamentação Teórica

8. Desenvolvimento

9. Metodologia

10. Resultados

11. Discussão

12. Conclusão

13. Recomendações

14. Referências Bibliográficas

15. Anexos (quando necessário)



Editor Profissional



Após gerar:



- Abrir editor semelhante ao Microsoft Word.

- Permitir editar qualquer texto.

- Alterar fontes.

- Alterar tamanho das letras.

- Inserir imagens.

- Inserir tabelas.

- Inserir gráficos.

- Salvar alterações.



Exportação



Permitir:



- Download em PDF.

- Download em DOCX (Microsoft Word).

- Salvar na conta do usuário.

- Compartilhar através de link.



Histórico



Guardar:



- Data de criação.

- Tema.

- Tipo de trabalho.

- Última edição.

- Downloads realizados.



Tecnologias



- Next.js

- TypeScript

- Supabase

- PostgreSQL

- Editor Rich Text

- Geração DOCX

- Geração PDF

- Sistema escalável e seguro



Diferencial da RuJe IA



A plataforma deve analisar o tema enviado e gerar trabalhos completos, bem estruturados, acadêmicos e profissionais, economizando horas de pesquisa para estudantes de Moçambique e outros países lusófonos.



Objetivo: tornar a RuJe IA 🇲🇿 a melhor plataforma africana de criação de trabalhos acadêmicos com Inteligência Artificial.
